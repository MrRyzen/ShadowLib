# 3D Degradable Backpack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `SpatialGraph3D<TOccupant>` into a self-contained 3D inventory box with killable cells, add the `Polycube` shape type, and delete `SparseGraph`.

**Architecture:** `Polycube` is a `readonly struct` mirroring `Polyomino` in three axes. `SpatialGraph3D` is rewritten in place over dense per-cell state sized to the box; neighbours are the six touching cells, computed from coordinates, so nothing stores connections. `SparseGraph.cs` goes away in the same task that removes the last reference to it.

**Tech Stack:** C# on `netstandard2.1` (library), NUnit on `net8.0` (tests), `net9.0` console runner.

**Spec:** `docs/superpowers/specs/2026-11-26-backpack-3d-design.md`. Read it before any task; its "Rules" and "Edge rules" lists are binding.

## Global Constraints

- Library stays `netstandard2.1`; no `UnityEngine` / `UnityEditor` in `Runtime/`; no new NuGet references.
- Randomness only through `IRandom`. `TryKillRandom` draws exactly once (`rng.Range(0, AliveCount)`) and not at all when `AliveCount` is 0.
- `TryKillRandom` and `FindPockets` do not allocate after warm-up.
- C# uses 4 spaces, `namespace X { using ...; }` layout as in the existing files, XML docs on every public member, no comments that narrate code.
- Every new tracked `.cs` needs a Unity `.meta`: run `bash scripts/generate-unity-meta.sh` after creating one and commit the `.meta` with it. Every deleted `.cs` loses its `.meta` in the same commit.
- Write file content with the Write/Edit tools, never bash heredocs.
- Tests seed with `new Xoshiro128StarStar(123UL)`. Test namespace is `ShadowLib.Tests`; fixtures are `[TestFixture] public class XTests`.
- Work on a feature branch `backpack-3d`. Commit after every task. Never push. End every commit message with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Test command for one fixture: `dotnet test Tests/Runtime/ShadowLib.Tests.csproj --filter "FullyQualifiedName~<FixtureName>"`.

## Review Focus

1. **A shape hangs off the high edge of the box.** With a flat index, `x = Width - 1` plus a 2-wide shape lands on the first cell of the next row. Expected: `CanPlace` is false, never a wrapped placement. Test in Task 2.
2. **Negative or out-of-box coordinates in queries.** Expected: false, no exception, no aliasing onto a real cell. Test in Task 2.
3. **An item is freed after a cell under it died.** Expected: the dead cell stays dead and is now empty, `AliveCount` is unchanged, and the item cannot go back. Test in Task 3.
4. **Pockets across a row or layer boundary.** The last cell of one row and the first of the next are adjacent in index but do not touch. Expected: two pockets. Test in Task 4.
5. **A struct occupant whose value is `default`** (`int` item `0`). Expected: it is a real item; `WasOccupied` is true and the cell reads as occupied. Test in Task 3.

**Interfaces:**

  - `SpatialGraph3D(int width, int height, int layers = 1, IEqualityComparer<TOccupant>? occupantComparer = null)`: any dimension `<= 0`, or a volume that overflows `int`, throws `ArgumentOutOfRangeException`
  - `int Width`, `int Height`, `int Layers`, `int Volume`, `int ExistingCount`, `int AliveCount`
  - `bool IsValidPosition(int x, int y, int layer = 0)`
  - `int GetIndex(int x, int y, int layer = 0)` = `layer * Width * Height + y * Width + x`

  - `bool AddCell(int x, int y, int layer = 0)`: outside the box throws `ArgumentOutOfRangeException`; false if the cell exists
  - `int AddPocket(Polycube shape, int x, int y, int layer = 0)`: zero-cell shape throws `ArgumentException`; any cell outside the box throws `ArgumentOutOfRangeException` and creates nothing; returns cells created
  - `bool Exists(int x, int y, int layer = 0)`, `bool IsAlive(int x, int y, int layer = 0)`
  - `bool CanPlace(int x, int y, int layer, Polycube shape)`
  - `bool Place(int x, int y, int layer, TOccupant occupant, Polycube shape)`: already-placed occupant throws `ArgumentException`
  - `bool Free(TOccupant occupant)`, `bool Contains(TOccupant occupant)`
  - `bool IsOccupied(int x, int y, int layer = 0)`, `bool TryGetOccupant(int x, int y, int layer, out TOccupant occupant)`
  - `int GetCells(TOccupant occupant, Span<(int X, int Y, int Layer)> buffer)`: ascending `GetIndex` order, at most `buffer.Length`, returns count written
- Internal shape later tasks build on: per-cell state held in dense arrays of length `Volume` indexed by `GetIndex` (exists / alive / occupied flags and the occupant), so Tasks 3 and 4 can scan cells in index order.
- Test helper later tasks reuse: `private static SpatialGraph3D<string> FullPack()` returning a `4 × 3 × 2` box with every cell added via `AddPocket(Polycube.FromBox(4, 3, 2), 0, 0, 0)`; and `private static readonly Polycube Crate = Polycube.FromBox(2, 2, 2);`.

- Produces:
  - `public readonly struct KilledCell<TOccupant>` with `int X`, `int Y`, `int Layer`, `bool WasOccupied`, `TOccupant Occupant`

  - `CanPlace` is false for any shape touching a dead cell. `AddCell` / `AddPocket` leave an existing dead cell dead.

[Test] public void TryKillRandom_DrawsOnce_ByRank_UntilNothingIsLeft()
{
    var pack = FullPack();
    var rng = new Xoshiro128StarStar(123UL);
    var reference = new Xoshiro128StarStar(123UL);
    var killed = new HashSet<int>();

    for (int alive = 24; alive > 0; alive--)
    {
        int rank = reference.Range(0, alive);
        int expected = -1;
        for (int index = 0, seen = 0; index < pack.Volume; index++)
        {
            var (x, y, layer) = pack.GetPosition(index);
            if (pack.IsAlive(x, y, layer) && seen++ == rank) { expected = index; break; }

        Assert.IsTrue(pack.TryKillRandom(rng, out var cell));
        Assert.AreEqual(expected, pack.GetIndex(cell.X, cell.Y, cell.Layer));
        Assert.IsTrue(killed.Add(expected));

    Assert.IsFalse(pack.TryKillRandom(rng, out _));
    Assert.AreEqual(reference.NextUInt(), rng.NextUInt());

}
